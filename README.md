# Recipies

Bu depo, **food recipies website** ödevi kapsamında oluşturulmuş bir web sitesini içerir.

## Proje Hakkında

- Kullanıcıların farklı yemek tariflerini görüntüleyebileceği bir arayüz sağlar.
- HTML, CSS ve temel JavaScript kullanılarak hazırlanmıştır.
- Tarifler statik olarak projeye dahil edilmiştir; gelecekte bir veritabanı ya da API entegrasyonu eklenebilir.

## Nasıl Kullanılır?
1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/esraevrim/recipies.git
   ```
2. `index.html` dosyasını bir tarayıcıda açın.
3. Menüden veya arama kutusundan istediğiniz tarifi bulun.

## Katkıda Bulunmak

Katkı yapmak isterseniz:
- Yeni tarifler ekleyebilir,
- Mevcut tasarımı iyileştirebilir veya responsive hâle getirebilirsiniz.
- Pull request oluşturarak değişikliklerinizi paylaşabilirsiniz.
